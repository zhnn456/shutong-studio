## 一、软件概览

### 1.1 产品定位

书童AI写作是一款 AI 辅助长篇小说（及剧本、构思画布）的桌面创作工作台：世界观设定、人物、关系、大纲、节拍、伏笔、地点、地图、图鉴、章节正文等元素围绕同一部作品组织，AI 以「可配置的创作协作者」身份参与整理设定、生成与修改章节，最终成稿可分层导出。

### 1.2 作品类型

书架首页支持三类独立内容【真机实测】：

| 类型 | 说明 | 典型元素 |
| --- | --- | --- |
| 小说（Novel） | 默认创作类型，本手册主线 | 章节、大纲、人物、关系、伏笔、地点、地图、设定/素材文档、图鉴、智能体规则 |
| 剧本（Screenplay） | 独立的剧本工程，含场次、分镜、制片片段、旁白设置 | 剧集、场次、场景角色与元素、分镜节拍、制片片段 |
| 画布（Canvas） | 独立的构思/制片画布作品 | 画布节点与连线 |

### 1.3 界面分区

**书架首页**【真机实测】：
- 左侧导航分四组：创作（小说 / 剧本 / 画布）、模型（AI 供应商 / 模型设置）、智能体（AI 助手 / 智能体技能 / 子智能体）、对话（快捷方式 / 最近对话）、设置（授权 / 设置 / 插件）、客服反馈。
- 顶栏三个建书入口：`导入 TXT`、`+ 新建小说`（空书表单）、`快速开书`（一句话想法）。
- 作品卡片点击进入对应作品的编辑器。

**作品编辑器**【真机实测 + 源码】：左侧栏按分组组织创作面板（系统：概览 / 图谱 / 进度 / 封面；创作：章节 / 大纲 / 人物 / 伏笔 / 素材；世界观：设定 / 地图 / 图鉴；AI：聊天 / 规则；灵感：圆桌 / 独白 / 剧场 / 扮演），中栏为对应面板或章节编辑器。

## 二、首次使用准备

### 2.1 启动软件【真机实测】

- 绿色版目录：`D:\shutong studio\reveric\dist\reveric-0.6.14-windows\`，双击 `reveric.exe`（同目录 `data/ depth/ dll/` 为依赖，请勿移动或删改）。
- 软件为单实例：重复启动不会开第二个窗口，而是把已有窗口提到前台。
- 数据存放：`C:\Users\Administrator\AppData\Roaming\ai.reveric\书童AI工作台\`（主库 `reveric.sqlite`；每部作品一个工作区库 `novel_workspaces\<作品ID>.sqlite`；附件在 `file_workspaces\<作品ID>\`；日志在 `logs\latest.log`）。

### 2.2 授权【真机实测】

- 首页侧栏 → 授权：查看当前版本（免费版 / 标准版 / 专业版）、设备绑定、有效期；可在此输入授权码激活或解绑本机。
- 本次测试环境：标准版，设备已绑定，有效期至 2027-11-16。

### 2.3 模型供应商配置【真机实测】

1. 首页侧栏 → **AI 供应商**。
2. 列表内建渠道：DeepSeek、秘塔科技、星辰AI（88API）、APIKEY.FAN；选中右侧详情可填写基础 URL、API 密钥、文本 / 图像 / 音频 / 视频 / 嵌入模型。
3. 启用状态以绿点标识；未启用渠道在配置密钥与模型后可打开。
4. 本次环境：DeepSeek 已启用并配置密钥（文本模型 deepseek-flash、deepseek-v4-pro）；其余三家未启用、无密钥。

### 2.4 角色级模型绑定（容易被忽略的一步）【真机实测】

- 首页侧栏 → **模型设置**：7 张角色卡——聊天对话、图像生成、正文写作、内容审查、文风润色、内容检索、事实梳理。
- **注意**：供应商启用不等于角色已绑定。本次环境 DeepSeek 供应商虽已启用，但 7 张角色卡全部「未选择」；需要为各角色指定具体模型后，对应创作动作才会走模型通道。

### 2.5 图像模型（封面出图前置）【真机实测】

- 封面 AI 生成依赖图像模型；本次 DeepSeek `image_models` 为空，封面「生成方案」按钮为灰色禁用。
- 如需封面出图：先在 AI 供应商中配置带图像模型的渠道，再回到模型设置的「图像生成」角色卡绑定模型。

### 2.6 其他准备项

- **网络代理**：设置 → 通用 → 网络代理（本次为「环境变量」方式）。
- **备份**：设置 → 存储 / 备份，支持本地备份与 WebDAV 备份配置【源码+历史库证据】。
- **MCP 服务**：首页侧栏 → MCP，粘贴 MCP 配置添加服务；未配置时为空态【真机实测】。

## 三、核心概念：元素是怎么被保存下来的（必读，避免「写完小说元素全空白」）

### 3.1 两套数据库【源码+历史库证据】

- **主库**：跨作品数据——作品条目、供应商、智能体、技能、会话、快捷方式、插件、阅读进度等。
- **工作区库**：单部作品内容——人物、关系、伏笔、大纲、节拍、地点、地图、文档、图鉴、章节、画布、规则、聊天消息等，每部作品独立一个 SQLite 文件。

### 3.2 元素建档的两条通道【源码+历史库证据】

每个创作元素（人物、伏笔、大纲、地点、文档……）都有两条写入通道：

1. **手动通道**：在编辑器对应面板点「新建」，在编辑器里填写并保存，直接写入工作区库。
2. **AI 通道**：AI 在会话中发起对应的建档工具调用（如创建人物、创建大纲、创建伏笔、创建地点、创建设定文档），工具执行后写入工作区库。

**关键机制**：AI 在对话里用自然语言说出的人物、设定、情节，**不会自动变成元素档案**；只有模型实际发起了建档工具调用（或你手动新建），内容才进入工作区表。对话文本本身只保存在聊天消息表里。

> 这正是历史作品中出现「有章节、有对话，但人物/伏笔/地点/文档全空」的原因：模型当时只做了阅读、写作或大纲类调用，没有发起实体建档工具。详见测试报告 §4 与源码审计 P1。

### 3.3 各元素落库规则一览【源码+历史库证据】

| 元素 | 工作区表 | 手动入口 | AI 工具通道 | 落库要点 |
| --- | --- | --- | --- | --- |
| 人物档案 | `character_profiles` | 人物面板 → 新建角色 | `/characters` 建档工具 | 双通道直写工作区库 |
| 人物关系 | `entity_relations` | 图谱面板 → 选中实体 → 添加关系 | `/relations` 工具 | 侧栏无独立「关系」菜单，从图谱面板或 AI 进入 |
| 伏笔 | `foreshadowings` | 伏笔面板 → 新建 | `/foreshadowing` 工具 | 可挂铺垫章 / 兑现章；挂载点允许为空 |
| 全书大纲 | `outlines` | 大纲面板 → 新建大纲 | `/outlines` 工具 | 大纲行与节拍在同一事务写入 |
| 章节节拍 | `outline_beats` | 大纲编辑器内节拍 chips / 对话框 | 大纲节拍工具 | **模型未返回节拍数组或解析失败时，大纲行存在而节拍为 0** |
| 地点 | `locations` | 地图工作室 → 新建地点 | `/locations` 工具 | 非世界根地点需挂父地点（`parent_id`） |
| 地图（图 + 点位归属） | `novel_maps`、`map_locations` | 地图工作室 | 图片生成通道 | **生成草稿先停留内存，必须点「采用」才落库**；未采用即离开页面，草稿丢失 |
| 世界观 / 设定文档 | `documents`（type=lore） | 设定面板 → 新建世界观 / 导入文件 | 文档创建 / 写入工具 | 素材文档为 type=material，同在素材面板 |
| 素材文档 | `documents`（type=material） | 素材面板 → 新建素材 / 导入文件 | 同上 | — |
| 图鉴（势力 / 生物 / 物品 / 技能） | `items`（按 type 区分） | 图鉴面板 → 新建条目 | `/items`、`/factions`、`/creatures`、`/skills` 工具 | 四类共用一张表与一套编辑 |
| 章节正文 | `chapter_nodes` | 章节树 → 新建卷 / 章 → 编辑器保存 | `/chapters` 工具 + 章节写入工具 | 正文直接更新；变更同时进入历史暂存 |
| 智能体规则 | `agent_rules` | 规则面板 → 新建 / 从其他作品复制 | 规则写 / 改 / 删工具 | 规则在 AI 运行时被加载，约束文风、视角与底线 |
| 构思画布 | `canvases`、`canvas_nodes`、`canvas_edges` | （实验功能） | 画布工具 | **默认构建关闭**：特性开关 `ENABLE_IDEATION_CANVAS` 默认 false，关闭时侧栏无入口；与剧本「制片画布」是两套东西 |

### 3.4 只进对话记录、不回写内容表的产物【源码+历史库证据】

圆桌（议事会）、独白、剧场、角色扮演四类会话模式：讨论与生成文本保存在会话消息表（`ai_chat_messages`），编排器本身不直接写人物 / 关系等内容表。讨论出的设定若要进入作品库，需要 AI 进一步发起建档工具，或你在对应面板手动整理。

### 3.5 流程顺序是建议，不是强制门控【源码+历史库证据】

源码中不存在「必须先写设定才能建人物」之类的数据库硬门控；先后顺序体现在侧栏分组、向导提示与建议横幅里。**但为了元素不空白、上下文连贯，建议按本手册第五章的顺序推进。**

## 四、开书：三种新建方式【真机实测】

| 方式 | 入口 | 适用场景 | 实测结果 |
| --- | --- | --- | --- |
| 空书表单 | 顶栏 `+ 新建小说` / 书架「新建小说」磁贴 | 从零手写，自己掌控全部设定 | 表单可打开；**作品名称必填**（非空且不可重名），作者名、简介、分类、标签、封面均可空；作品类型可选原创 / 改编 / 续作 / 同人 / 二创 / 资料 |
| 快速开书 | 顶栏 `快速开书` | 只有一句话想法，交给创作向导展开 | 单框输入故事想法；建库后进入编辑器，设定交给创作向导；占位标题为「未命名作品」 |
| 导入 TXT | 顶栏 `导入 TXT` | 已有章节文稿，先成稿再补设定 | 原生文件选择框 → 预览对话框（识别卷 / 章数，作品名默认取文件名）→ 开始导入；**章节标题需匹配「第 X 章 / 节 / 回」格式**；无标题则章节清空并提示「未识别到章节」 |

> 实测：导入路径成功建主库行、建工作区库、章节正文与字数回写编辑器；导入只写章节，不产生人物 / 大纲 / 伏笔等元素（这些需在后续步骤补齐）。

## 五、标准创作路径（从零到完本，推荐顺序）

> 每一步给出：入口 → 怎么做 → 产出与落库 → 衔接下一步 → 常见卡点。
> 顺序对应源码侧栏分组；跳步不会被软件拦截，但跳步越靠后，回头补设定的成本越高。

### 步骤 0 · 检查配置

- **入口**：AI 供应商、模型设置。
- **动作**：确认文本渠道已启用且有密钥；7 张角色卡已绑定模型（至少「聊天对话」「正文写作」「文风润色」）；需要封面则配置图像模型。
- **卡点**：供应商已启用但角色卡未绑定 → 对应动作仍显示未选择；图像模型为空 → 封面按钮禁用。

### 步骤 1 · 作品简介

- **入口**：编辑器 → 系统 · 概览 / 简介编辑器。
- **动作**：填写书名（建书时已填）、一句话简介、分类、标签、作者名。
- **产出**：主库作品条目更新。
- **衔接**：简介是后续 AI 生成设定与人物的上下文基础。

### 步骤 2 · 世界观与设定文档

- **入口**：编辑器 → 世界观 · 设定（`documents` type=lore）；素材资料放素材面板（type=material）。
- **怎么做**：
  - 手动：新建世界观文档，分节记录时代背景、地理、势力、规则、特殊设定；可用导入文件补充。
  - AI：在聊天中明确要求「把世界观整理成设定文档并建档」，由 AI 发起文档建档工具；完成后到设定面板核对内容是否出现。
- **产出落库**：`documents`（lore）；素材进 `documents`（material）。
- **衔接**：人物与地点都要引用世界观中的势力、地理与规则。
- **卡点**：AI 只在对话里描述设定、未发起建档工具时，设定面板仍为空——回到面板手动新建，或在对话中明确要求「写入设定文档」。

### 步骤 3 · 人物档案

- **入口**：编辑器 → 创作 · 人物。
- **怎么做**：
  - 手动：新建角色，填写姓名、角色定位（主角 / 配角等）、性别、别名、标签、传记、外貌、声口等字段。
  - AI：要求「根据设定文档创建主要人物档案」；AI 调用人物建档工具后，回到人物面板核对。
- **产出落库**：`character_profiles`。
- **衔接**：下一步人物关系依赖已建档的人物与实体。
- **检查**：人物面板列表数量与工作区 `character_profiles` 行数一致；传记 / 外貌字段非空。

### 步骤 4 · 人物关系与实体图谱

- **入口**：编辑器 → 系统 · 图谱（关系图谱）；筛选维度：角色 / 势力 / 技能 / 物品 / 生物。
- **怎么做**：选中两个实体 → 添加关系，填写关系类型、当前状态与变更说明；AI 可通过 `/relations` 工具批量建立。
- **产出落库**：`entity_relations`。
- **卡点**：人物档案编辑器内没有独立的关系填写区；关系只能从图谱面板或 AI 工具创建（源码审计 P3）。
- **衔接**：关系网为后续章节冲突与伏笔提供依据。

### 步骤 5 · 地点与地图

- **入口**：编辑器 → 世界观 · 地图（地图工作室）。
- **怎么做**：
  1. 先建世界根地点，再建子地点（非根地点必须挂父地点）；
  2. 需要地图图时触发生成草稿 → **核对草稿与点位 → 点击「采用」**，地图与点位归属才落库；
  3. AI 可通过 `/locations` 工具建档地点。
- **产出落库**：`locations`；采用后写入 `novel_maps`、`map_locations`；地图图像进资产库。
- **卡点**：
  - 直接建子地点而无父地点 → 工具返回参数错误；先建根地点。
  - 草稿未点「采用」就离开页面 → 草稿在内存中，不落库、重启后丢失（源码审计 P4）。

### 步骤 6 · 全书大纲与章节节拍

- **入口**：编辑器 → 创作 · 大纲（`outlines`）；大纲编辑器内管理节拍（`outline_beats`）。
- **怎么做**：
  - 手动：新建大纲，写主线、分卷、关键转折；在大纲内拆分章节节拍。
  - AI：要求「生成全书大纲并按章节拆分节拍」；保存后核对大纲条目与节拍 chips。
- **产出落库**：`outlines` + `outline_beats`（同一事务写入）。
- **卡点**：模型省略节拍数组或节拍解析失败时，大纲行存在而节拍为 0；此时在大纲编辑器手动补拆节拍，或要求 AI 重新输出节拍（源码审计 P2）。
- **衔接**：章节正文按大纲与节拍推进。

### 步骤 7 · 图鉴（势力 / 生物 / 物品 / 技能）

- **入口**：编辑器 → 世界观 · 图鉴。
- **怎么做**：按四类标签新建条目；复杂设定（功法、道具、组织、种族）在此建档，供章节与关系引用。
- **产出落库**：`items`（type=faction / creature / item / skill）。
- **可选**：视题材需要跳过；悬疑、现实题材可只保留少量关键物品。

### 步骤 8 · 章节正文

- **入口**：编辑器 → 创作 · 章节；章节树管理卷与章，正文编辑器写稿。
- **怎么做**：
  1. 新建卷 / 章；按大纲节拍写本章目标、阻力、代价、章末钩子；
  2. AI 辅助：聊天中要求生成 / 扩写 / 续写本章；工具栏含刷新、历史版本、文件夹、预览、AI、保存，以及替换、一键排版；
  3. 保存即写入章节正文；字数实时统计；变更进入历史暂存，可在历史版本中恢复。
- **产出落库**：`chapter_nodes`（标题、细纲、简报、正文、字数、草稿状态）。
- **检查**：界面字数与章节条目一致；主库作品总字数为各章合计。

### 步骤 9 · 伏笔埋设与回填

- **入口**：编辑器 → 创作 · 伏笔。
- **怎么做**：记录伏笔标题、铺垫内容、兑现内容、铺垫章 / 兑现章；写到对应章节时回填挂载点。AI 可通过伏笔建档工具创建；章节推进后回到伏笔面板核对铺垫 / 兑现状态。
- **产出落库**：`foreshadowings`。
- **建议**：大纲阶段就列出主线伏笔，章节阶段逐章回填，避免完稿后伏笔表空白。

### 步骤 10 · 智能体规则（文风与底线约束）

- **入口**：编辑器 → AI · 规则。
- **怎么做**：新建规则（叙事视角、文风禁令、设定边界、章节规格等），或从其他作品复制；规则在 AI 运行时被加载。
- **产出落库**：`agent_rules`。
- **历史库参考**：既有作品中规则最长可达上万字，用于固化文风与连续性约束（测试报告 §10）。

### 步骤 11 · 审校与历史

- **入口**：章节编辑器工具栏 → 历史版本；AI 模式中的审查 / 润色（内容审查、文风润色角色卡）。
- **机制**：AI 与手动编辑先进入暂存变更，提交后形成版本记录；可回溯历史快照【源码+历史库证据】。
- **待人工复验**：暂存变更在异常中断后的恢复 / 清理路径（源码审计 P8）。

### 步骤 12 · 导出完本

- **入口**：书架作品卡片菜单（`…`）→ 导出小说。
- **可选范围**【源码+历史库证据，正文范围已真机实测】：大纲、章节大纲、设定资料、创作素材、正文；输出为分层目录或 ZIP；章节号格式（中文 / 数字）、标题对齐等选项在导出表单中。
- **实测结果**：仅勾选「正文」时导出单个 `正文.txt`，书名 + 章节标题 + 两章正文与工作区库逐段一致。
- **待人工复验**：其余四个范围的分节文件内容一致性，以及 ZIP 压缩格式。

## 八、常见问题（FAQ）

**Q1：AI 在对话里讲了人物和设定，为什么人物面板还是空的？**
A：对话文本只进会话消息表；人物 / 设定需要 AI 发起建档工具调用，或你在对应面板手动新建。提问时明确说「写入人物档案 / 设定文档」，并在生成后回面板核对。

**Q2：大纲建好了，但节拍（章节拆分）是空的？**
A：模型省略了节拍数组，或节拍解析失败；大纲行已独立提交。在大纲编辑器手动补拆节拍，或要求 AI 按章节数重新输出节拍。

**Q3：在哪里编辑人物之间的关系？**
A：人物档案编辑器内没有关系区；打开「系统 · 图谱」，选中实体后添加关系；也可让 AI 通过关系工具建档。

**Q4：地图生成了，为什么地图列表里看不到？**
A：地图草稿先生成在内存中，必须在地图工作室点「采用」，地图与点位归属才落库；未采用就离开页面，草稿不保存。

**Q5：创建子地点时报参数错误？**
A：非世界根地点必须挂父地点。先建一个 world 类型根地点，再在其下建子地点。

**Q6：封面「生成方案」按钮是灰色的？**
A：当前供应商未配置图像模型。到 AI 供应商添加图像渠道，并在模型设置的「图像生成」角色卡绑定模型。

**Q7：供应商已经启用，为什么各角色动作还是提示未选择模型？**
A：供应商启用与角色级模型绑定是两步。到模型设置，为聊天对话、正文写作、文风润色等角色卡分别指定模型。

**Q8：AI 会话弹出问题卡片后停住不动了？**
A：这是 AskUser 问询挂起；回答卡片上的问题（章节体量、故事底色等）后，模型才继续生成。

**Q9：导入 TXT 后章节没进去？**
A：章节标题需匹配「第 X 章 / 节 / 回」格式；无识别标题时会提示「TXT 文件未识别到章节」。整理文稿标题后重新导入。

**Q10：圆桌 / 独白 / 剧场 / 扮演讨论出的结论会自动进作品库吗？**
A：不会自动回写。会话产物留在对话记录；需要建档的人物、关系、设定，再让 AI 发起建档工具，或手动整理到对应面板。

**Q11：导出时可以只导出正文，或连同大纲设定一起导出吗？**
A：可以。导出表单勾选范围（大纲 / 章节大纲 / 设定资料 / 创作素材 / 正文），选择分层目录或 ZIP。

**Q12：数据保存在哪里？会丢吗？**
A：主库与每部作品的工作区库都在 `%APPDATA%\ai.reveric\书童AI工作台\` 下；建议在设置 → 备份中配置本地备份或 WebDAV 备份。
