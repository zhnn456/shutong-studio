# 原创初始化流程

在当前作品上下文中的 `type` 为 original 且用户确认「从零原创」时使用。

本流程的目标不是「确认几条难改的基础决策」，而是**交付一套能直接开工的骨架**：世界观、核心角色、分卷大纲、逐章纲目。骨架规范以 `SKILL.md` 第 5 节为准，本文档只说明原创模式特有的是什么、按什么顺序问。

## 1. 先读，再问（不重复已有内容）

1. 读小说元数据、已有世界观（`/lore`）、角色、势力、大纲、章节。
2. 读已有 AgentRules。
3. 列缺口：L1 缺什么、L2 五段各缺什么、哪些已有资料可直接复用。
4. 已有且方向一致的内容不问；只在「用户的判断与已有内容冲突」时才问一次。

## 2. 三轮硬决策（只问三轮）

### 第一轮：方向

1. 题材与目标读者（已有 `category`/`tags` 时展示现值让用户确认）
2. 一句话故事承诺：读者追读时稳定获得什么体验
3. 主角要达成的核心目标，以及阻止他的核心对立

### 第二轮：量级与分卷

1. 全书篇幅量级：目标章数或万字量级（网文可给区间，如 100–150 章 / 30–45 万字）
2. 分几卷、每卷大致章节范围
3. 单章字数（默认 2000–3000 字，浮动 10%）

建议切法：<50 章不分卷或 2 卷；50–150 章 3–5 卷；>150 章 5–8 卷。AI 只建议，不擅自定卷。

### 第三轮：不可逆结构（按题材挑 2–3 个维度）

- 世界/舞台与社会秩序
- 能力、资源、职业或竞争规则，以及硬上限和代价
- 主要势力、关系格局与长期冲突
- 信息边界：谁知道什么，真相如何逐步揭示
- 现实、史实、行业或科学边界（有真实历史背景时必须问，否则会成为硬伤来源）

只问会连锁影响全书的项，不追问细节。**第三轮结束立即进入生成流程，不再增加提问轮次。**

## 3. L1 落盘（先给确定的东西）

按顺序写入，不要等：

1. 书名（占位名给 3–5 个候选；已有正式名只问是否调整）
2. 分类（从题材参考挑 2–4 个最贴项）
3. 标签（能准确描述题材、角色、情节的少量标签，逗号分隔）
4. 简介（空时给一句草稿；已有时展示并问是否修改）
5. 写作行为 AgentRules 7–10 条：章节字数、文风、视角、节奏、章末钩子、禁忌
6. 若 `draft` 为 true，问一次是否现在加入书架

## 4. L2 骨架（五段，按此顺序，缺一不可）

### A. 世界观 5 条

写进 `/lore`，每条独立条目 150–300 字：

1. 世界结构与时代（地理、空间、时间锚点）
2. 秩序与制度（谁掌权、规则怎么运行、普通人怎么活）
3. 力量/能力体系（来源、硬上限、代价、禁忌）
4. 势力格局 3–5 家（目标 + 冲突 + 与主角关系）
5. 信息边界（谁知道什么，何时揭示）

有真实历史背景的作品（史实、朝代、地域、宗教、制度），这一段的每条都要先与已确认的史实边界对齐，冲突处标 `[推演]` 并说明依据。**历史题材不许出现"看起来像那个朝代但其实不可能"的设定**（如唐代已有但当时不存在的技术、官职、宗教组织形态）。

### B. 核心角色 6–8 张

写进 `/characters`，每人 9 字段全填：身份与年龄、外貌一个可辨识特征、性格 3 个行为标签、想要什么、怕什么、不会做什么、能力与资源（含上限与代价）、与主角的关系张力、弧光。

**每个角色必须占一个功能位**：对手、推进器、镜像、信息源、代价。占不到就删。主角一个人拥有多种能力时，把每种能力的来源与代价写进世界观第 3 条，避免写成无敌主角。

### C. 分卷大纲

两件事都要做：

1. **章节树卷节点**：`Create /volumes`，`title` 用卷名，`outline` 传卷简介。不建卷节点，章节会全部平铺在根目录。
2. **大纲轨道**：每卷一条 `/outlines`，400–600 字，含卷目标、三步推进、卷末反转或代价、与下一卷的交接钩，`start_chapter_num` 卷间连续无缝。

若为多线叙事（如主线 + 暗线 + 感情线），各线独立成轨道，标题写清用途（「主线：第一卷」「暗线：幕后身份」），不要为了模板完整新建空轨道。

### D. 逐章纲目

写进 `/chapters`，每章：

- 标题：有信息量，不用「第 X 章」充数
- 必传 `volume_id`：挂到 C 段建好的卷节点，跨卷时不会挂错
- `brief` 梗概：60–100 字，写谁做了什么、局面变成什么
- `outline` 章纲：本章唯一主目标变化 + 冲突 + 章末钩子
- 引用：出场角色、涉及势力、埋设或回收的伏笔
- `content` 留空，不写正文

按卷分批，单批 ≤35 章，每卷生成后 AskUser 确认一次再落下一卷。**每一章都要有标题与梗概**；当前卷的 `outline` 写全，其余卷的 `outline` 留空，轮到该卷时补齐。

### E. 自检（7 条，不过就回炉）

1. 章纲角色名都能在角色表查到
2. 每条伏笔 setup/payoff 配对且 payoff 在后
3. 各卷章数之和 = 全书章数，`start_chapter_num` 连续
4. 每个核心角色 ≥3 章登场，首登不晚于第一卷
5. 力量体系的上限与代价在章纲里没有被无代价突破

## 5. 结束检查

结束前必须能回答，且答案都已落盘：

- 这本书向谁承诺什么体验？主角为何必须行动，主要阻力是什么？
- 世界观 5 条是否各有独立条目、彼此不矛盾？
- 核心角色是否 6–8 张、9 字段全填、功能位不重复？
- 卷数、章数与用户确认的量级是否一致？
- 每一卷的每一章是否都有标题与梗概？
- 自检 7 条是否全过？

任一项不满足时，补齐该项再回报，不得只报告"基础引导完成"。
